What is Claude Code?
Two ways to wield AI power
Explored

Claude Code comes in two flavors, and you'll want to use both depending on what you're doing. Think of them as two cockpits for the same spaceship.

Claude Code CLI Claude Desktop
Where Your terminal Desktop app

When to use which? If you're about to write or edit code, reach for the CLI. If you're thinking through a problem, planning architecture, or want a visual artifact, open the Desktop app.

Claude Code CLI
Your command center
Explored

Claude Code CLI is where the real magic happens. It lives in your terminal and can read, write, and execute files on your machine. It's like having a senior developer pair-programming with you 24/7.

Getting started:

# Install Claude Code globally npm install -g @anthropic-ai/claude-code # Navigate to your project and launch cd my-project claude # Or start a brand new project claude "Create a React app with a todo list"

Key slash commands you'll use constantly:

  • /help -- see all available commands
  • /model -- switch between Opus, Sonnet, Haiku models
  • /clear -- reset the conversation context
  • /compact -- summarize the conversation to free up context
  • /cost -- see how much of your usage you've spent

Power move: Create a CLAUDE.md file in your project root. This is like a "cheat sheet" Claude reads every time it starts. Put your project conventions, tech stack info, and preferences in there. Claude will follow them automatically.

Claude Desktop App
Your visual thinking partner
Explored

The Claude Desktop app (at claude.ai or the native macOS/Windows app) is your thinking partner. While the CLI is for building, the Desktop app excels at conversations, planning, and creating visual artifacts.

What makes it special:

  • Artifacts -- Claude can generate interactive React components, diagrams, documents, and more right in the chat
  • Projects -- organize conversations by topic, add reference files Claude can always access
  • File uploads -- drag in images, PDFs, code files for Claude to analyze
  • Conversation history -- everything is saved and searchable

Workflow combo: Use Desktop to brainstorm your architecture and plan, then switch to CLI to actually build it. Desktop for the "what," CLI for the "how."

Cowork Mode
Code together with Claude
Explored

Cowork is one of the coolest features exclusive to your MAX plan. It turns Claude into a background coding partner that watches what you're working on and proactively helps.

How it works:

  • Claude monitors your code changes in real-time
  • It can suggest improvements, catch bugs, and offer refactors
  • You stay in the driver's seat -- Claude assists, you decide
  • Think of it like having a code reviewer watching over your shoulder (in a good way!)
# Start Claude Code in cowork mode claude --cowork # Or use the /cowork command inside a session /cowork

Best for: Longer coding sessions where you want a safety net. Cowork catches the bugs you'd normally find hours later in testing.

Dispatch
Send out your fleet
Explored

Dispatch is the newest and most powerful feature in the Claude Code ecosystem. It lets you orchestrate multiple Claude agents in parallel -- like having a whole team of developers at your command.

What you can do:

  • Parallel tasks -- ask Claude to work on multiple files or features simultaneously
  • Sub-agents -- Claude spawns focused workers for specific jobs, then synthesizes the results
  • Complex projects -- break down an entire app into pieces and have agents tackle each part
  • Research + Build -- one agent researches the approach while another starts scaffolding
# Example: Claude dispatches agents for parallel work claude "Build a full-stack todo app. Create the API, frontend, and database schema in parallel." # Claude automatically dispatches sub-agents: # Agent 1: Database schema design # Agent 2: REST API endpoints # Agent 3: React frontend components

This is a MAX exclusive. Dispatch uses significantly more compute, which is why it requires a MAX plan. Use it for bigger tasks where parallelism actually helps -- small scripts don't need it.

Essential Plugins
Supercharge your setup
Explored

Claude Code supports plugins that extend its capabilities. These are the ones you'll want to install right away:

Superpowers -- The must-have plugin. Adds brainstorming workflows, test-driven development, systematic debugging, code review, and skill-based workflows. Makes Claude dramatically more effective.

claude plugin add superpowers

Context7 -- Gives Claude access to up-to-date documentation for libraries and frameworks. Instead of relying on training data, Claude fetches the latest docs in real-time.

claude plugin add context7

GitHub -- Full GitHub integration: create PRs, review code, manage issues, browse repos -- all from the CLI.

claude plugin add github

Start with Superpowers. It's the biggest quality-of-life improvement. Context7 is great once you start working with specific frameworks. GitHub plugin becomes essential when you're pushing code.

MCPs & Connectors
Connect Claude to everything
Explored

MCP (Model Context Protocol) is how Claude connects to external tools and services. Think of MCPs as "USB ports" for Claude -- each one plugs in a new capability.

What MCPs can do:

  • Filesystem -- read/write files, search directories
  • Browser control -- navigate websites, extract data, fill forms
  • Databases -- query SQL databases, manage data
  • APIs -- connect to Slack, Notion, GitHub, Jira, and hundreds more
  • Desktop control -- automate your computer, run scripts

Connectors are pre-built, first-party MCPs from Anthropic that make setup painless. Instead of configuring an MCP manually, connectors handle authentication and setup for popular services.

Don't overwhelm yourself. Start with the basics (filesystem + GitHub) and add MCPs as you actually need them. The MCP registry has hundreds of community-built connectors for almost anything.

Claude in Chrome
Let Claude see your browser
Explored

Claude can control your Chrome browser through MCP integrations. This is wild -- it can navigate pages, read content, fill forms, take screenshots, and interact with web apps.

Real use cases:

  • Web scraping -- extract data from any website, even dynamic JavaScript-rendered pages
  • Testing -- have Claude test your web app by actually clicking through it like a real user
  • Automation -- fill out repetitive forms, navigate complex workflows
  • Research -- ask Claude to read a webpage and summarize it, or compare multiple pages
  • Debugging -- Claude can inspect console logs, network requests, and DOM elements

Think bigger: Claude in Chrome isn't just for developers. You can use it to automate any browser workflow -- research, data entry, monitoring dashboards, testing user flows. It's like having a robot assistant that can use any website.

Pro Tips & Next Steps
Level up your game
Explored

You've got the tools. Here's how to think like a power user from day one:

CLAUDE.md -- Your Secret Weapon:

  • Create a CLAUDE.md file in any project root
  • Tell Claude your preferences: coding style, frameworks, testing approach
  • Add project-specific context: "this is a Next.js app using Prisma and PostgreSQL"
  • Claude reads this file automatically every session -- it's persistent memory for your project

Prompt engineering tips:

  • Be specific -- "Add a login form with email/password using React Hook Form and Zod validation" beats "add login"
  • Give context -- "I'm building a social app for dog owners" helps Claude make better decisions
  • Iterate fast -- don't try to get it perfect in one shot. Build, review, refine
  • Use extended thinking -- for complex problems, Claude's thinking mode produces much better results

First project ideas for you, Cohen:

  • Build a personal portfolio site with Claude from scratch
  • Create a CLI tool that does something useful for your workflow
  • Clone a simple app you like (todo, weather, notes) to learn the patterns
  • Automate something annoying with a script + Claude in Chrome

The #1 rule: Don't be afraid to ask Claude anything. There are no dumb questions. The more you use it, the faster you'll learn what it's capable of. Break things, experiment, and have fun with it.
