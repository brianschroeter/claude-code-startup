What is Claude Code?
Two ways to wield AI power
Explored

Claude Code comes in two flavors, and you'll want to use both depending on what you're doing. Think of them as two cockpits for the same spaceship.

Claude Code CLI Claude Desktop
Where Your terminal Desktop app
Best for Building, coding, file ops Brainstorming, planning, chat
Superpower Reads & writes your files directly Artifacts, visual outputs

When to use which? If you're about to write or edit code, reach for the CLI. If you're thinking through a problem, planning architecture, or want a visual artifact, open the Desktop app.

Claude Code CLI
Your command center
Explored

Claude Code CLI is where the real magic happens. It lives in your terminal and can read, write, and execute files on your machine. It's like having a senior developer pair-programming with you 24/7.

Getting started (pick your platform):

# macOS (recommended) brew install --cask claude-code # Windows (PowerShell) irm https://claude.ai/install.ps1 | iex # Linux / macOS alternative curl -fsSL https://claude.ai/install.sh | bash # Navigate to your project and launch cd my-project claude # Auto-generate a CLAUDE.md for your project /init

Note: The old npm install -g @anthropic-ai/claude-code method is deprecated. Use the native installer above -- it auto-updates and has zero dependencies. Windows users: install Git for Windows first.

Key slash commands you'll use constantly:

  • /help -- see all available commands
  • /model -- switch between Opus, Sonnet, Haiku models
  • /clear -- reset the conversation context
  • /compact -- summarize the conversation to free up context
  • /cost -- see how much of your usage you've spent
  • /effort -- set thinking level to low, medium, or high. Low effort = fast, concise answers for simple questions. High effort = deep reasoning for complex problems. This saves your MAX usage on easy stuff and unleashes full power when you need it

VS Code Extension -- GUI or Terminal, your call:

Claude Code also has an official VS Code extension (anthropic.claude-code) that gives you two ways to work:

  • GUI mode -- a dedicated side panel with visual diff review, inline code suggestions, @-mentions to reference files, and a chat interface right in your editor
  • Terminal mode -- run claude in VS Code's integrated terminal for the full CLI experience without leaving your editor
  • Both modes share conversation history, settings, and MCP configurations -- start in the GUI, switch to terminal, pick up right where you left off
  • Also works in Cursor and Windsurf editors

Power move: Create a CLAUDE.md file in your project root. This is like a "cheat sheet" Claude reads every time it starts. Put your project conventions, tech stack info, and preferences in there. Claude will follow them automatically.

Cowork Mode

Cowork is one of the coolest features exclusive to your MAX plan. It's an agentic workspace where Claude operates directly on your computer -- reading, editing, and creating files while you focus on the big picture.

What Cowork can do:

# Cowork is accessed via the Claude Desktop app's Cowork tab # Open Claude Desktop → click the Cowork tab to switch modes # Or use scheduled tasks /loop every morning, review my overnight PRs

Computer Use just launched (March 2026)! Claude asks permission before accessing each new app, and you can stop it at any point. Try asking it to open your browser, navigate to a site, and extract data -- it's like having a robot assistant on your desktop.

Dispatch
Send out your fleet
Explored

Dispatch and Agent Teams are the most powerful features in Claude Code. They let you orchestrate multiple Claude agents working in parallel -- like having a whole development team at your command.

Dispatch (from your phone!):

  • Pair your phone to your desktop via QR code scan (takes under 2 minutes)
  • Assign tasks from anywhere -- Claude works on your desktop while you're away
  • Come back to finished work, review the results, and iterate
  • Maintains context across sessions -- no re-explaining needed

Agent Teams (the real game-changer):

  • A team lead agent spawns independent teammate agents
  • Each teammate gets their own isolated git worktree -- no conflicts
  • They coordinate through a shared task list and direct messaging
  • Perfect for complex projects where multiple parts can be built simultaneously
# Claude dispatches an Agent Team: # Team Lead: Orchestrates the project # Teammate 1: Database schema (own worktree) # Teammate 2: REST API endpoints (own worktree) # Teammate 3: React frontend (own worktree) # Bonus: Voice Mode (rolling out!) # Hold spacebar to talk to Claude # Supports 20 languages

Heads up: Agent Teams are experimental and disabled by default -- you'll need to enable them with a flag. They work best with the Opus 4.6 model and use significant compute. Use them for bigger tasks where parallelism matters -- small scripts don't need a whole team. Also try Voice Mode (hold spacebar) for hands-free coding!

Essential Plugins
Supercharge your setup
Explored

Claude Code supports plugins that extend its capabilities. These are the ones you'll want to install right away:

Superpowers -- The must-have plugin. Adds brainstorming workflows, test-driven development, systematic debugging, code review, and skill-based workflows. Makes Claude dramatically more effective.

claude plugin add superpowers

Context7 -- Gives Claude access to up-to-date documentation for libraries and frameworks. Instead of relying on training data, Claude fetches the latest docs in real-time.

claude plugin add context7

GitHub -- Full GitHub integration: create PRs, review code, manage issues, browse repos -- all from the CLI.

claude plugin add github

Start with Superpowers. It's the biggest quality-of-life improvement. Context7 is great once you start working with specific frameworks. GitHub plugin becomes essential when you're pushing code.

MCPs & Connectors
Connect Claude to everything
Explored

MCP (Model Context Protocol) is how Claude connects to external tools and services. Think of MCPs as "USB ports" for Claude -- each one plugs in a new capability.

What MCPs can do:

  • Filesystem -- read/write files, search directories
  • Browser control -- navigate websites, extract data, fill forms
  • Databases -- query SQL databases, manage data
  • APIs -- connect to Slack, Notion, GitHub, Jira, and hundreds more
  • Desktop control -- automate your computer, run scripts

Connectors are pre-built, first-party MCPs from Anthropic that make setup painless. Instead of configuring an MCP manually, connectors handle authentication and setup for popular services.

Don't overwhelm yourself. Start with the basics (filesystem + GitHub) and add MCPs as you actually need them. The MCP registry has hundreds of community-built connectors for almost anything.

OpenAI's Codex is another powerful coding agent. It's not a competition -- smart developers use both. Here's how they compare and complement each other:

Claude Code OpenAI Codex

Using them together (the power move):

  • Plan with Claude -- brainstorm architecture and design in Claude Desktop or CLI
  • Build with Claude Code -- real-time interactive coding for core implementation
  • Batch with Codex -- assign repetitive tasks (test generation, migrations, refactoring) to Codex for async parallel execution
  • Review with both -- get a second opinion on PRs by having both review your code

Community consensus: Claude Code leads on code quality and developer experience. Codex leads on cost efficiency and async workflows. The savviest developers use both -- Claude Code for the "flow state" interactive work, Codex for the "fire and forget" batch jobs.

Skills & Skill Builder
Teach Claude new tricks
Explored

Skills are reusable workflows and instructions that Claude Code can follow. Think of them as "playbooks" -- when you invoke a skill, Claude loads a set of expert instructions and follows them precisely. They're one of the most powerful ways to get consistent, high-quality results.

How skills work:

  • You invoke a skill with a slash command like /frontend-design or /brainstorming
  • Claude loads the skill's instructions and follows them step-by-step
  • Skills can include checklists, workflows, and best practices that Claude will enforce
  • They come from plugins -- install a plugin to unlock its skills

Recommended skills to start with:

  • frontend-design -- Generates distinctive, production-grade UI with exceptional design quality. Avoids generic "AI slop" aesthetics. This very page was built using it!
  • brainstorming -- Turns rough ideas into fully-formed designs through Socratic questioning before you write any code
  • test-driven-development -- Write tests first, watch them fail, then implement. Enforces disciplined TDD workflow
  • systematic-debugging -- Four-phase debugging framework: investigate root cause, analyze patterns, test hypotheses, then implement fixes
  • writing-plans -- Creates detailed implementation plans with exact file paths and code examples

The Skill Builder:

Here's the really cool part -- you can create your own skills. The Skill Builder (/skill-creator) lets you:

  • Design custom workflows tailored to your specific projects
  • Test skills with sub-agents before deploying them
  • Iterate and refine skills until they're bulletproof
  • Share skills with others via the plugin ecosystem
# Browse available skills /help # Use a skill directly /frontend-design Build a dashboard for my app # Create your own custom skill /skill-creator

Start by using skills, then build your own. Once you notice yourself repeating the same workflow (like "always lint before committing" or "always check tests after changes"), that's a perfect candidate for a custom skill. Skills turn your best practices into enforced habits.

Pro Tips & Next Steps
Level up your game
Explored

You've got the tools. Here's how to think like a power user from day one:

CLAUDE.md -- Your Secret Weapon:

  • Create a CLAUDE.md file in any project root
  • Tell Claude your preferences: coding style, frameworks, testing approach
  • Add project-specific context: "this is a Next.js app using Prisma and PostgreSQL"
  • Claude reads this file automatically every session -- it's persistent memory for your project

Prompt engineering tips:

  • Be specific -- "Add a login form with email/password using React Hook Form and Zod validation" beats "add login"
  • Give context -- "I'm building a social app for dog owners" helps Claude make better decisions
  • Iterate fast -- don't try to get it perfect in one shot. Build, review, refine
  • Use extended thinking -- for complex problems, Claude's thinking mode produces much better results

Starter project ideas for you, Cohen (easiest to most ambitious):

  • Personal website (10 min) -- your name, bio, links. Use /init + one prompt. Learn the basics
  • Retro space shooter game (30 min) -- HTML5 Canvas game with enemies and power-ups. Fun and visual
  • CLI quiz game (20 min) -- trivia on any topic you love. Learn core coding concepts
  • AI study buddy (1-2 hrs) -- generates flashcards from your notes using the Claude API. Learn API integration
  • Personal command center (2-4 hrs) -- Cowork skills + Dispatch from your phone. Morning briefings, homework organizer
  • Multi-agent research machine (6-10 hrs) -- parallel agents that research, organize, and summarize topics. The ultimate capstone

Platform tips:

  • Windows users: Install Git for Windows first, use PowerShell or WSL 2. Keep projects in the Linux filesystem if using WSL
  • Mac users: Cowork requires Apple Silicon (M1+) and the Claude Desktop app. Install the CLI via brew install --cask claude-code
  • VS Code users: Install the official Claude Code extension for inline diffs, @-mentions, and visual diff review

The #1 rule: Don't be afraid to ask Claude anything. There are no dumb questions. The more you use it, the faster you'll learn what it's capable of. Break things, experiment, and have fun with it.
